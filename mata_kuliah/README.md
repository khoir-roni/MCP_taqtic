# Arsip Catatan Mata Kuliah S2

Setiap mata kuliah disarankan memiliki subfolder masing-masing, misalnya:
- `metodologi_penelitian/`
- `filsafat_ilmu/`
- `seminar_proposal/`

### Format Penamaan Berkas:
Gunakan format penamaan seragam:
`pertemuan_01_pengantar.md`, `pertemuan_02_paradigma_riset.md`, dst.
Gunakan template dari `../templates/template_catatan_kuliah_s2.md`.
