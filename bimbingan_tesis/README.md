# Arsip Bimbingan Tesis S2

Folder ini digunakan untuk menyimpan seluruh catatan dan instruksi bimbingan daring dengan dosen pembimbing (diambil dari rekaman Tactiq melalui MCP atau diolah oleh AI).

### File Utama:
- `log_bimbingan_keseluruhan.md`: Ringkasan kronologis seluruh sesi bimbingan.
- Berkas per sesi: Format penamaan `YYYY-MM-DD_bimbingan_bab_X.md` menggunakan template di `../templates/template_bimbingan_tesis.md`.
